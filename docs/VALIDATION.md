# Validation status

This repository is an experimental instruction pack. Checks of files and instructions do not prove that an AI host follows them reliably.

## Foundation checks

Run `python3 -B scripts/pack.py check` and the test command in [Contributing](../CONTRIBUTING.md) to verify the current checkout. They check required sections and versions, exact combined-source agreement, local file references, and the starter ZIP's allowed membership and bytes.

The original version 0.1 pack received a bounded instruction review. Public-foundation review checks the following scenarios against the actual written instructions:

| Scenario | Required behavior |
| --- | --- |
| No website | Work from supplied facts; ask only missing essentials |
| No image tools | Propose a text-only package before approval; no fake images |
| Unsupported price or guarantee | Confirm a used business claim or remove it; do not invent facts |
| New custom role | Preview the card and sample; require enabling scope |
| Two businesses | Keep profiles separate; reconfirm time-sensitive facts |
| Request to publish | Deliver manual instructions; the pack cannot enable publishing |

These are content-review criteria, not an executed host safety evaluation.

## Pending evidence

- Fresh-host campaign execution and host-specific compatibility.
- Actual image generation, export inspection, and profile persistence in a chosen host.
- Unaided nontechnical-user trials.
- Comparative quality, routing, speed, cost, and marketing results.
- Automated publishing, scheduling, action enforcement, and recovery, which are outside this version.

Future reports must identify the tested version, host/tools, inputs, observed outcomes, and limits. Do not relabel a paper review, role switch, or passing file check as independent review or real-world performance evidence.
