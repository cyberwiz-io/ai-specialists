The adapter files in `adapters/claude-code/agents/` are generated by the build from the cards and the coordinator boundaries; never edit them by hand. To change one, edit its card in `catalog/` or the generator in `scripts/packlib/adapter.py`.

1. `python3 -B scripts/pack.py build`, then `python3 -B scripts/pack.py check`.
2. `python3 -B -m unittest discover -s tests -p "test_adapter.py"`.
3. `git status --short adapters/` and summarize which agents changed and why (card edit, coordinator edit, or generator change).

Report that the adapter is experimental, outside the shipped pack, and has no host evidence yet. Do not commit.
