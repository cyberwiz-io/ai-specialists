# Claude Code adapter (experimental)

Generates one Claude Code subagent per specialist card, so a Claude Code user can delegate to a role by name instead of pasting a pack. It lives outside the shipped pack and the release archive on purpose: the [roadmap](../../docs/ROADMAP.md) asks that an adapter document its tested host and evidence first.

## Status

| Item | State |
| --- | --- |
| Tested Claude Code version | Not yet tested |
| Fresh-host delegation behavior | Not observed |
| Evidence | None yet: the [card evals](../../evals/README.md) harness exists but no run is recorded, and it tests cards, not this adapter |
| Shipped in the pack or release ZIP | No |

Do not rely on this adapter for sensitive work. The cards remain working perspectives, not expert review.

## Files

`agents/<role-id with / as ->.md`, for example `agents/software-engineering-code-reviewer.md`. They are generated by `python3 -B scripts/pack.py build` from the cards and the Boundaries section of each family's coordinator; never edit them by hand. `check` fails if one is stale.

Each file has:

- `description`: "Materials-only specialist." plus the card's first Use for sentence. It does not ask Claude to delegate proactively.
- `tools: Read, Grep, Glob`: read-only, so a role cannot run commands, edit files, browse or contact anyone. The card's materials-only rule is backed by the host here, which the pack alone cannot do.
- `model: inherit`.
- A short note on those limits, the coordinator's Boundaries (plus Sensitive domains for the four sensitive families), then the card text unchanged.

## Use

Copy the files you want into a project's `.claude/agents/` folder or into `~/.claude/agents/`, then ask Claude Code to use a role by name. Copy only the roles you need; all 124 would crowd the delegation menu.

## Limits

- Subagents cannot call other subagents. A card's Handoff line is a recommendation that the main conversation acts on.
- A subagent returns text to the main conversation. Nothing here saves files, keeps a profile or persists state.
- Claude Code settings, other plugins or a project's own rules may add tools or override behavior. The read-only list applies only to these files.
- The cards are unchanged, so every card limit and unchecked area still applies.
